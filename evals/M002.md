# M002: Microsoft quarterly investor summary

This is a bounded FI experiment for Microsoft's FY2027 Q1 Form 10-Q, accession
`0001193125-26-436133`, covering July 1–September 30, 2026 and the same quarter in
2025. The original `financial-report-eval` experiment is unchanged.

## Run

Use FI's Python environment from the repository root. No dependencies were added.
The report runner loads root `.env` with process-environment values taking
precedence. Set an identifying `SEC_USER_AGENT` with a real contact email and an
`OPENAI_API_KEY`. `.env` is ignored and its contents are never written to artifacts.

```powershell
# Validate the integrated M001 fixture offline.
python -m src.evaluation.ground_truth

# One SEC download and one Responses API call; no automatic model retry.
python evals/run.py --report-baseline --download

# Or use the exact previously downloaded HTML snapshot, without a SEC request.
python evals/run_report.py --snapshot data/raw/sec/filings/MSFT/0001193125-26-436133/20261029T181655Z_198f9e545b5d.html

# Re-evaluate the actual saved live run, without any network/model calls.
python evals/run.py --report-baseline --evaluate-run evals/reports/m002/20261029T182225Z_684dec81
```

Without `--download` or `--snapshot`, the runner selects a cached snapshot of the
pinned accession, verifies its checksum, and pins that exact file for processing.
Missing cached data fails; another filing is never substituted. General filing
discovery supports recent submissions only and fails explicitly for an accession
outside that list.

The existing filing runner also accepts selection arguments:

```powershell
# As before, this runner requires SEC_USER_AGENT in the process environment.
python run_filings.py MSFT --form 10-Q --accession 0001193125-26-436133
python -m src.retrieval.search_filings "revenue" --ticker MSFT --accession 0001193125-26-436133
```

Default filing ingestion remains latest 10-K. Default lexical searches retain the
annual corpus; an accession filter searches only that filing, including a 10-Q.

## Architecture and artifacts

Existing SEC fetch/retry and raw snapshots feed form-specific section extraction,
existing Parquet section storage, and deterministic chunks. M002 evidence packets
select four bounded windows: income statement, segment table, recast disclosure,
and management summary. Each packet retains source/section/text hashes, part/item,
section character offsets, and overlapping chunk IDs. Table cells remain delimited
by row; column periods, units, and segment labels remain present.

The one-call generator receives only report metadata, requested metric/topic
definitions, and independently extracted evidence. It never loads the oracle or
expected conclusions. Its structured fields render directly into Markdown, so
there is no second unchecked narrative response. M002 reuses the Responses API
pattern but does not change the annual analyst or its risk generator.

Each run under `evals/reports/m002/<run_id>/` contains:

- `generated.json`, `summary.md`: original structured output and rendered summary.
- `source.json`, `sections.json`, `evidence.json`: source metadata/hash and exact supplied evidence.
- `run.json`, `generation.json`: status, model, prompt version, response ID, usage, and model latency.
- `instructions.txt`, `output_schema.json`: prompt instructions and output contract.
- `ground_truth.json`: evaluation oracle archived **after** generation, never model input.
- `evaluation.json`, `review_template.json`: automatic results and unresolved human review.

Re-evaluation verifies evidence against saved section spans and provenance, then
uses the archived ground-truth snapshot. A checksum establishes byte identity,
not independent source authenticity or semantic correctness. Failed runs retain
available inputs and a sanitized error type; they never fabricate model output.

## Evaluation and human review

The evaluator compares all 12 values using exact Decimal arithmetic in declared
units. Correctly grouped thousands separators are normalized; malformed grouping,
scientific notation, nonfinite values, and unit substitutions are rejected. Six
YoY percentages must equal the oracle-derived one-decimal ROUND_HALF_UP values.

Metadata, citation integrity, quote membership, and numeric support are separate
results. Numeric support requires the correct labeled row in the appropriate
table, current/prior column context, matching values, and a quotation containing
that row. Segment quotations must also contain the segment label. A valid source
reference or true but unrelated quotation cannot satisfy numeric support.

Human reviewers must assess each entire interpretation note against the supplied
disclosures, including any numbers, causal language, scope, and omissions:

| Case | Review criterion |
|---|---|
| `gaap_vs_non_gaap` | Distinguish reported net income/EPS from adjusted non-GAAP measures; verify any stated adjustment. |
| `recast_segment_comparability` | Confirm prior segment amounts use the current recast structure; reject comparisons with unrecast amounts. |
| `azure_growth_vs_cloud_margin` | Distinguish Azure revenue growth from Microsoft Cloud gross margin percentage, including level versus change and any claimed driver. |

Copy a run's `review_template.json` to a separate review file. For each case,
record `status` as `pass` or `fail`, a nonempty `reviewer`, a `rationale` explaining
the evidence comparison, and the cited `evidence_ids`. Leave uncertain cases
`pending_manual_review`. Then:

```powershell
python evals/run_report.py --evaluate-run evals/reports/m002/<run_id> --reviews path/to/review.json
```

Exit codes: **0** = all automatic and human checks pass; **2** = automatic checks
pass but human review is pending or failed; **1** = automatic failure or incomplete
execution. Pending human reviews never count as passes. Re-evaluation replaces
`evaluation.json` but preserves the raw generation.

## Actual live baseline

Exactly one live model call was made for run `20261029T182225Z_684dec81` using
`gpt-5-mini`, prompt `m002-v1`. Model latency: **32.718 seconds**. Usage:
**5,687 input tokens**, **3,815 output tokens**, **9,502 total tokens**.
The source HTML SHA-256 is recorded in `source.json` (prefix `198f9e545b5d`).

| Check | Result |
|---|---|
| Financial values | 12/12 |
| YoY changes | 6/6 |
| Labeled table support | 6/6 |
| Metadata, citation integrity, quote membership | Pass |
| Qualitative reviews | 3/3 pass; overall pass is true; exit code 0 |

The first evaluator rejected comma-formatted values and quotations lacking outer
table delimiters, yielding 2/12 values and 0/6 row-support checks despite correct
figures. That result is preserved as `evaluation.initial.json`. Evaluator
`m002-eval-v2` normalizes valid presentation formatting, with focused regression
tests. The unchanged saved model output was re-evaluated; no second model call
was made. `run.json` records this history.

Human review assisted by ChatGPT confirmed all three interpretation notes against
the saved evidence packets. Decisions, rationales, and evidence IDs are recorded
in the separate local `review.json`. Offline re-evaluation with that file set
`run.json` to `completed_reviewed`; the original model output is unchanged.
To reproduce the reviewed result, supply
`--reviews evals/reports/m002/20261029T182225Z_684dec81/review.json`
with the saved-run command above. Run artifacts remain ignored by Git.

Final local Python verification: **297 passed, 0 failed, 0 skipped** in 32.64
seconds. Four existing HTML-versus-XML parser warnings were emitted by the three
real annual filings and the quarterly filing. All 226 pre-existing tests passed.
No dbt models changed and no dbt build was run for this milestone.

Quarterly extraction and evidence selection support this observed Microsoft
layout only. Changed/missing anchors or table context fail closed. Part II risk
factors are outside M002. No quarterly Gold models, UI changes, new services, or
general report orchestration are introduced. One Q1 example does not establish
coverage of later quarters, YTD values, amendments, other companies, or layouts.

M001's qualitative navigation labels “Financial Summary” and “Segment Results of
Operations” are descriptive rather than exact headings in this HTML: the observed
headings include “SUMMARY RESULTS OF OPERATIONS” and “Reportable Segments.” The
integrated oracle preserves M001; extraction uses actual source boundaries and
does not trust those navigation labels as proof of support.
