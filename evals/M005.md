## Outcome and review status

The shared quarterly pipeline now processes the pinned CAT 2026 Q1 10-Q using
deterministic financial assembly and one qualitative model call. Offline and live
runs pass exact numeric, table-support, provenance and reconciliation checks.
Both Microsoft profiles retain their existing contracts and pass read-only replay.

**The live narrative is not acceptable for approval as written.** In
`gaap_vs_non_gaap`, the saved model says restructuring costs were "$41 in 2026"
and "$33 in 2025" without stating millions. The source table means **USD 41
million and USD 33 million**. This is a material unit ambiguity in standalone
prose. The automatic checks correctly do not claim semantic entailment. There
was exactly one live call, no retry, no rewriting of its output, and no human
approval. Implementation/generation stopped on observing this defect. A saved
investor presentation is an unapproved review draft, not a release candidate.

Oracle review, all three qualitative reviews and presentation review remain
pending. `automatic_pass: true` does not imply `overall_pass: true`.

## Independent financial oracle

`evals/ground_truth/cat_2026_q1.json` was transcribed from the original statement
and Note 16 tables before generation. It was not derived from model output or
production table extraction. It records exact values, units, accounting basis,
periods, source table, row, columns and printed filing page. A human should still
review the transcription before accepting it as a reviewed oracle.

All four consolidated current/prior pairs independently match cached CompanyFacts
observations from the same accession and exact start/end dates. This is a
cross-check of the same issuer disclosures, not an independent economic source.
CompanyFacts does not provide the segment oracle. The four concepts are
`Revenues`, `OperatingIncomeLoss`,
`NetIncomeLossAvailableToCommonStockholdersBasic`, and `EarningsPerShareDiluted`.

- `src/analytics/report_profiles.py`: CAT source/period metadata, explicit metric
  roles and table bindings, topic windows, display labels and reconciliation rows.
  Existing Microsoft configuration dictionaries remain unchanged.
- `src/transformation/parse_filings.py`: retain the observed Part I TOC extraction;

  CAT prompt version is `m005-assembly-v1`; no Azure instructions are sent.
- `evals/run_report.py`: select the profile ticker instead of hardcoded MSFT;
  require deterministic assembly for the new contract. Existing defaults stay
  unchanged. CAT runs default to the M005 output parent.
- `src/evaluation/report_ground_truth.py` and `report_evaluation.py`: preserve
  Microsoft rules; validate CAT scope, periods and reconciliation explicitly.
  CAT evaluation version is `m005-eval-v1`.
- `src/ai/report_generator.py`: include reconciliation in the saved technical
  summary only when present. Existing Microsoft summaries reproduce unchanged.
- `src/analytics/investor_report.py`, `src/evaluation/investor_report.py`, and
  `evals/render_investor_report.py`: company labels, role-based segments and exact
  bridge display. CAT versions are `m005-presentation-v1` and
  `m005-presentation-eval-v1`.
- `tests/test_cat_report.py` and `tests/fixtures/cat_2026_q1_excerpt.html`: compact
  real-source-derived excerpt contracts, independent expected values, negative
  cases, controlled generation and draft tests. The excerpt is explicitly not an
  authentic complete raw filing. Existing Microsoft fixture parametrization is
  scoped to its original two layouts; all original test cases remain.

The ordinary investor renderer still rejects pending semantic reviews. An

No dependencies, services, agent systems, JPM reporting, quarterly dbt models or
